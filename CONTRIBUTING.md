# Contributing / 贡献指南

[English](#english) | [中文](#chinese)

## English

Before publishing any release or replacing its downloadable assets, finish the changes, checks and release package, then ask Ewigkeit1203 for explicit confirmation. Wait for that confirmation before publication. Local builds and tests may proceed while awaiting review.

For bugs, provide DSH version, OS, reproduction steps and optional Doctor output. Doctor includes selector counts only. Remove private chat content and credentials from screenshots. Run `npm run build`, `npm run typecheck`, `npm test` and `node --check lib/client.js` before submitting code. Preserve default mute, local-only preferences, no persistent chat history and no extra content-sharing services.

Artwork submissions must identify the rights holder, source, intended license, permission for redistribution and any AI assistance. Acceptance of AI-generated artwork and broader artwork licensing remain maintainer decisions. Do not submit third-party work without the necessary permission. See [artwork permissions](ASSETS_LICENSE.md).

## 中文

任何新版本发布或已发布安装包替换，都必须先完成修改、检查和打包，再向 Ewigkeit1203 展示结果并请求明确确认；确认前不得发布。本地构建和测试可以先行完成。

问题反馈请提供 DSH 版本、系统、复现步骤和可选的 Doctor 输出。Doctor 仅含选择器匹配数量；截图应去掉私人对话与凭据。提交代码前运行构建、类型、测试及运行包语法检查。保留默认静音、偏好仅本地保存、不持久化聊天历史、不向额外服务分享内容的约定。

美术投稿须说明权利人、来源、拟采用许可、再分发权限和 AI 辅助情况。是否接受 AI 生成投稿，以及更广泛的美术授权范围，由维护者决定。不得提交未获必要授权的第三方素材。参见[美术授权说明](ASSETS_LICENSE.md)。
