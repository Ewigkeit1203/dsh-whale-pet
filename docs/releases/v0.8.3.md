# v0.8.3 · 只有一个她、桌面回顾与修复 / One of her, desktop Log and fixes

## 中文

- **只有一个她：** 桌面版连上并显示她时，DSH 里的她会暂时离开；桌面版隐藏、退出或断开后，她回到 DSH。正常退出桌面版时 DSH 立刻知道，不用等超时。
- **去桌面／回 DSH：** 设置最上面有两个大按钮：在 DSH 里是“去桌面陪我”和“进入剧场模式”，在桌面版里是“回 DSH 里陪我”。桌面版没运行时会说明怎么启动。
- **桌面剧场的回顾：** 按 L 或点“回顾”，会向 DSH 读取当前会话里已经加载的问答（最近 40 条，不含推理），可以复制；在 DSH 里切换会话，开着的回顾会跟着换。只在打开回顾时读取，关上就不保留。DSH 没连上、没有打开的会话或插件版本不一致时会说明原因。回顾只显示 DSH 已加载到页面的内容，不是完整历史。
- **修复：** 在 DSH 里退出账号、切换账号或撤销余额权限后，桌面上不再一直显示上一个账号的余额。桌面版卡住时，DSH 里的她不会一直藏着。
- **下载更干净：** Releases 只放 ZIP，不再附带 `.sha256` 文件（GitHub 在每个附件旁显示其 SHA-256）。桌面版下载包在发布前会逐字节检查：只含运行需要的文件，不含任何模型。

**插件：** 下载 **dsh-whale-pet-v0.8.3.zip**，解压到原来的插件目录覆盖，双击 **install.bat**（目录没变可以跳过），在 DSH 按 Ctrl+R。设置、互动记录和导入的模型都会保留。

**桌面版：** 下载 **dsh-whale-pet-desktop-v0.8.3-win-x64.zip**，解压到任意文件夹，双击 **DaFeiYu.exe**，不需要 Node.js。要和 DSH 联动，DSH 里的插件也需要是 v0.8.3（旧插件连上时，回顾会提示更新）。桌面版有自己的设置，Live2D 模型需要在它的设置里再导入一次；模型不随下载包提供。退出：右键托盘里的蓝色小圆图标。

桌面模式还是预览。

验证：Node 自动测试、构建、两套类型检查，Windows 上的插件包与安装／卸载检查、桌面版打包与 ASAR 逐字节检查；桌面回顾在 Electron 中用真实的桌面版与模拟的 DSH 页面联调检查过（读取、切换会话、截断、空会话、断开与重连、旧插件提示）。

## English

- **Only one of her:** while the desktop app is connected and shows her, she steps out of DSH; she comes back there when the desktop app hides her, quits or disconnects. A normal quit tells DSH at once instead of waiting for a timeout.
- **To the desktop and back:** two large buttons at the top of Settings: in DSH, “Keep me company on the desktop” and “Open theatre”; in the desktop app, “Back into DSH”. When the desktop app is not running, she says how to start it.
- **Log in the desktop theatre:** L or Log reads the messages already loaded in DSH's current conversation (the most recent 40, without reasoning), ready to copy; switch conversations in DSH and an open Log follows. It reads only while open and keeps nothing once closed; when DSH is not connected, has no conversation open or runs a different plugin version, she says why. Log shows what DSH has loaded on the page, not the full history.
- **Fixes:** after signing out, switching accounts or revoking balance access in DSH, the desktop no longer keeps showing the previous account's balance. A stuck desktop app can no longer keep her hidden in DSH.
- **Cleaner downloads:** Releases carry only the ZIPs, without `.sha256` side files (GitHub shows each asset's SHA-256 next to it). The desktop download is checked byte for byte before release: only the files it runs, never a model.

**Plugin:** download **dsh-whale-pet-v0.8.3.zip**, extract it over your plugin folder, run **install.bat** (optional if the folder did not move) and press Ctrl+R in DSH. Preferences, discoveries and the imported model are kept.

**Desktop app:** download **dsh-whale-pet-desktop-v0.8.3-win-x64.zip**, extract it anywhere and double-click **DaFeiYu.exe**; no Node.js needed. To connect with DSH, the plugin inside DSH must be v0.8.3 too (with an older plugin, Log asks you to update it). The desktop app has its own settings; import the Live2D model once more there (the model is not included). Quit from the small blue round tray icon.

Desktop mode is still a preview.

Validation: automated Node tests, build, both TypeScript checks, Windows plugin package and install/uninstall checks, desktop packaging with byte-for-byte ASAR checks; the desktop Log was checked in Electron with the real desktop app against a simulated DSH page (reading, conversation switch, truncation, empty conversation, disconnect and reconnect, older-plugin notice).
