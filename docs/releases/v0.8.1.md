# v0.8.1 · 余额、提醒与互动修复 / Balance, reminders and interaction fixes

## 中文

- **余额与提醒：** 五种明确的余额状态、详情与刷新/重试入口、可配置头顶标签和每日低余额提醒。后台完成回答后可标记标题，回来时提醒一次，也可关闭。
- **上手与导入：** 三步引导移到角色身旁，新增本机互动图鉴；Live2D 导入卡提供获取链接、进度和文件夹拖放。
- **安装目录整理：** 只需双击根目录 install.bat 或 uninstall.bat；必需的 PowerShell 辅助脚本放在 installer/，请保留该文件夹。启动器仍兼容旧版根目录脚本布局。

- **五项修复：** 账户切换清除旧余额和旧请求；余额不足只依据宿主明确的任务错误，避免示例文字误报；异常图鉴日期不会让设置崩溃；关闭提醒会取消待提醒和标题标记；连续摸尾巴保持害羞、提示休息，不再触发戳人生气。
- **安装包更清楚：** 辅助脚本收进 installer 文件夹。安装、重复安装、目录移动升级和卸载均在中文及特殊字符路径中检查；修改配置前备份，保留相邻插件与本机偏好。

下载 **dsh-whale-pet-v0.8.1.zip**，完整解压到固定目录，双击根目录 **install.bat**，在 DSH 按 Ctrl+R。保留 lib、installer 与 docs；不要只复制 BAT，也不要在 ZIP 中直接运行。从 v0.8.0 升级保留设置、互动记录和同一 DSH 存储环境里导入的模型。

**dsh-whale-pet-installer-fix-v0.8.1.zip** 只修复已有插件目录的安装工具，不含插件运行文件。将其中两个 BAT 和整个 installer 文件夹复制到旧插件根目录；它不能单独安装。

模型可选且不随包重新分发。获取链接在设置的角色模型卡片；原画及拆分：神宫凉子，Live2D 建模：霓虹猫_NeonNeko。已撤回的摆尾实验不包含在本版本。

验证：196 项 Node 回归、构建、两套类型检查、浏览器包语法、Windows 启动器和解压包安装/卸载检查。账户切换与异常状态由模拟宿主覆盖；DSH 账户服务暂时不可用时会显示失败并重试，不保证宿主一定返回余额。

## English

- **Balance and reminders:** five clear balance states, refresh/retry details, configurable head chips and a daily low-balance reminder. Answers completed while DSH is in the background can mark the title and greet you once when you return; reminders can be disabled.
- **Getting started:** a three-step guide beside her, a local interaction gallery and a clearer Live2D import card with the model download link, progress and folder drop support.
- **Installer layout:** double-click the root install.bat or uninstall.bat. Their required PowerShell helper is in installer/; keep that folder with the package. Legacy root-level helper layouts remain supported.

- **Five fixes:** invalidate old balance reads and both sources on account changes; require an explicit host quota failure instead of searching answer prose; reject invalid gallery dates; cancel disabled answer reminders and title marks; keep tail strokes shy with a specific request for a break rather than poke anger.
- The complete archive and installer-only repair archive are checked from their extracted files, including actual BAT entry points, CRLF/BOM, repeated installation, upgrades, configuration backups and safe uninstallation.

Extract **dsh-whale-pet-v0.8.1.zip** completely into a permanent folder, run root-level **install.bat**, then refresh DSH with Ctrl+R. Keep lib/, installer/ and docs/ intact. Upgrading over v0.8.0 retains preferences, discoveries and the imported model in the same DSH storage environment.

The installer-fix archive contains no runtime and cannot install independently; copy both BAT files and its installer/ directory beside an existing lib/ directory. The optional Live2D model is not redistributed. The withdrawn tail experiment is excluded.

Validation: 196 Node tests, build, both TypeScript checks, bundle syntax, Windows launcher and archive installation/uninstallation checks. Account edge cases use a simulated host; unavailable host balance services are shown honestly and retried.
