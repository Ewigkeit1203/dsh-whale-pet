# v0.8.4 · 桌面回顾修复 / Desktop Log fix

## 中文

- **修复：桌面剧场的回顾读不到消息。** DSH 把会话标识放在标题栏、消息排在它旁边时，回顾现在也能读到当前会话已加载的问答。它只读取包含这些消息的最近范围，不超出页面；同一范围里出现别的会话标识时宁可不显示，绝不把不同会话混在一起。

**插件：** 下载 **dsh-whale-pet-v0.8.4.zip**，解压到原来的插件目录覆盖，双击 **install.bat**（目录没变可以跳过），在 DSH 按 Ctrl+R。设置、互动记录和导入的模型都会保留。

**桌面版：** 下载 **dsh-whale-pet-desktop-v0.8.4-win-x64.zip**，解压到任意文件夹，双击 **DaFeiYu.exe**。要和 DSH 联动，DSH 里的插件也需要是 v0.8.4。模型不随下载包提供，需要在桌面版设置里导入一次。

v0.8.3 的全部内容见 [v0.8.3 发布说明](v0.8.3.md)。桌面模式还是预览。

验证：Node 自动测试、构建、两套类型检查，Windows 上的插件包与安装／卸载检查、桌面版打包与 ASAR 逐字节检查；桌面回顾在 Electron 中用真实的桌面版与模拟的 DSH 页面联调检查过，包括标题栏与消息并排、同一范围出现第二个会话的情形。

## English

- **Fix: Log in the desktop theatre found no messages.** When DSH puts the conversation identity on a header beside the messages, Log now reads the messages already loaded in the current conversation. It reads only the nearest scope that holds the messages, within the page; if another conversation marker appears in that scope it shows nothing rather than mixing conversations.

**Plugin:** download **dsh-whale-pet-v0.8.4.zip**, extract it over your plugin folder, run **install.bat** (optional if the folder did not move) and press Ctrl+R in DSH. Preferences, discoveries and the imported model are kept.

**Desktop app:** download **dsh-whale-pet-desktop-v0.8.4-win-x64.zip**, extract it anywhere and double-click **DaFeiYu.exe**. To connect with DSH, the plugin inside DSH must be v0.8.4 too. The model is not included; import it once in the desktop app's settings.

Everything in v0.8.3 is in the [v0.8.3 notes](v0.8.3.md). Desktop mode is still a preview.

Validation: automated Node tests, build, both TypeScript checks, Windows plugin package and install/uninstall checks, desktop packaging with byte-for-byte ASAR checks; the desktop Log was checked in Electron with the real desktop app against a simulated DSH page, including a header beside its messages and a second conversation in the same scope.
