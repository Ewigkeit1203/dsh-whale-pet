## 中文

- **设置面板更稳定。** 修复窗口模式和全屏之间切换时设置变成顶部小块的问题；面板保持可读高度，正文在内部滚动。空间不足时独立面板居中显示。
- **散步更自然。** 每次重新随机等待 8～20 秒，目的地覆盖 DSH 窗口内可用区域，可横向、纵向移动；保留边界约束，不移到屏幕外。
- **不再每次走完都吃饭。** 大多数时候回到待机，约四分之一概率吃饭休息。操作菜单、拖拽、思考、回答或后台状态下暂停散步，并取消积压动作。
- **明确社区贡献流程。** 欢迎通过 PR 投稿，合并前须审查和测试；正式发布及下载附件替换须由 Ewigkeit1203 明确同意。接受 AI 制作或辅助美术，但必须形象统一、来源清楚并有必要授权，禁止未经授权的第三方图片。

构建、类型、运行包语法及 **94 项测试通过**。已在实际 DSH 中检查窗口与全屏设置。协作规则不代表 GitHub 强制分支保护已启用。

下载 **dsh-whale-pet-v0.5.2.zip**，完整解压覆盖原插件目录，运行 install.bat，在 DSH 按 **Ctrl+R** 刷新。原有偏好保留。安装包附 SHA-256 校验文件。

## English

- **Stable settings.** Fix settings collapsing into a small top-aligned block when switching between windowed and maximized views. The panel keeps a readable height and scrolls its content; detached panels are centred when space is limited.
- **Less predictable strolls.** Sample a fresh 8–20 second wait and a destination across the available DSH viewport, including vertical movement, while keeping the character inside the window.
- **Varied endings.** Most strolls return to idle; roughly one in four ends with a rice break. Menu interaction, dragging, model activity and background state pause wandering without a backlog.
- **Clear contribution rules.** PRs need review and testing before merge. Ewigkeit1203 must explicitly approve releases and downloadable-asset replacements. AI artwork is welcome when consistent with the character and supported by clear sources and permissions; unauthorized third-party images are prohibited.

Build, type checking, bundle syntax and **94 tests passed**. Windowed/maximized settings were checked in DSH. The collaboration policy does not itself enable GitHub branch protection.

Extract **dsh-whale-pet-v0.5.2.zip** over the existing plugin directory, run install.bat and press **Ctrl+R** in DSH. Preferences are retained. A SHA-256 checksum is included as a separate download.
