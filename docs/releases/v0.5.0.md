# v0.5.0 — Balance at a glance, 梁文峰 time, and a calmer stage / 余额一眼可见、梁文峰时间，以及更从容的舞台

## English

This release rebuilds the interface around the character: settings never cover her, every pose has the same size, and the balance and DeepSeek pricing period are always one glance away.

### Highlights

- **Balance without opening settings.** When DSH provides its account service, 大肥鱼 reads your balance the same way DSH's own account card does. She refreshes it every minute, when you return to the window and after each answer, and clears it as soon as you sign out. The plugin never handles credentials. Unread amounts show as —, never ¥0.00; older values are marked “not live”.
- **梁文峰 / 梁文谷 time.** A small chip above her head shows the current DeepSeek API pricing period and when it ends, in your local time. When DSH opens and at every switch she tells you: “现在是梁文峰时间！” (peak) or “现在是梁文谷时间！” (off-peak). Peak is Beijing time, weekdays 09:00–12:00 and 14:00–18:00; weekends and Chinese public holidays are off-peak at half price. You can turn announcements off in Settings › Companionship.
- **Settings never cover her.** The panel stays beside the character with a fixed gap, slides to the other side near screen edges, and opens as a separate panel in very narrow windows. She stops wandering while it is open.
- **Rebuilt settings.** Fixed header, scrolling body, a balance card, a pricing-period card and a roomy footer.
- **Consistent portraits.** Every pose is calibrated to the same head size and foot line. 撒娇 no longer looks smaller, and changing pose no longer shifts her.
- **Your name, everywhere.** Her lines use the name you set instead of “你”.
- **Smoother.** Dragging, hovering and streaming do far less work, so fast drags with settings open no longer stutter.
- **New character voice.** Soft speech blips follow the text as it appears, with pauses at punctuation. They stop promptly when output stops, never replay missed text and skip code. Sound is still muted by default.
- **Theatre.** A regrouped header, her face stays visible in expanded reading, clearer reading surfaces, and full reading only follows new text while you are at the bottom.
- **Fresh look.** Rebuilt light and dark themes, keyboard access to the character and clear focus states.

Chibi form switching is paused for now; its artwork is kept. If you were using the chibi form, the portrait is shown instead.

### Install / upgrade

Download **dsh-whale-pet-v0.5.0.zip**, fully extract it to a permanent folder, run **install.bat**, then press **Ctrl + R** in DSH. To upgrade, replace the files in the same folder, or rerun the installer if you moved it. Your settings are kept. DSH supplies React and Cordis; no Node.js is needed.

### Good to know

- Balance through the account service needs a signed-in DeepSeek account in DSH. With an API key only, DSH has no balance to show; opening DSH's account settings still works as a fallback on older DSH versions.
- The public-holiday table covers 2026. Until next year's official schedule is added, a weekday public holiday in 2027 may show as peak, and Settings says so.
- Checked in a simulated DSH page with the real plugin bundle. Validation: build, typecheck, bundle syntax and **84 automated tests**. Please report anything that looks different in your DSH version.
- No conversation history is stored or sent anywhere; preferences stay on your computer.

## 中文

本版围绕角色重新整理了界面：设置面板不再挡住她，每个姿态大小一致，余额和 DeepSeek 计费时段随时一眼可见。

### 主要更新

- **不用打开设置也能看到余额。** DSH 提供账户服务时，大肥鱼会按 DSH 自带账户卡片的方式读取余额：每分钟、回到窗口时和每次回答结束后各刷新一次，退出登录后立即清空。插件不接触任何凭据。未读取显示 —，不会显示成 ¥0.00；旧数据会标注“非实时”。
- **梁文峰 / 梁文谷时间。** 头顶小标签显示当前 DeepSeek API 计费时段和结束时间（按本机时间）。打开 DSH 时和每次时段切换时，她会告诉你“现在是梁文峰时间！”（高峰）或“现在是梁文谷时间！”（空闲）。高峰为北京时间工作日 9:00–12:00、14:00–18:00；周末和法定节假日为空闲时段，价格减半。可在 设置 › 陪伴行为 中关闭播报。
- **设置面板不再挡住她。** 面板始终贴在角色旁边并保持间距；靠近屏幕边缘时平滑换到另一侧；窗口太窄时改为独立面板。设置打开期间她会停止游荡。
- **设置面板重做。** 固定标题、可滚动正文，新增余额卡片和计费时段卡片，底部区域更宽松。
- **立绘大小一致。** 每个姿态都按同样的头部大小和脚底位置校准，撒娇不再显小，切换姿态时她也不会移位。
- **处处使用你的称呼。** 台词会用你设置的称呼，不再直接说“你”。
- **更流畅。** 拖动、移动鼠标和流式输出时的计算量大幅减少，打开设置时快速拖动不再卡顿。
- **新的人物音效。** 随文字出现发出轻柔的说话音，遇到标点会停顿；输出停止后很快安静，不补播漏掉的内容，代码不发声。仍默认静音。
- **剧场。** 顶部按钮重新分组；大屏阅读时能看到她的脸；阅读区域更清晰；完整阅读模式只在你停留在底部时才跟随新文字。
- **全新外观。** 明暗主题重新设计，角色支持键盘操作，并有清晰的焦点提示。

Q 版切换暂时关闭，素材保留；之前使用 Q 版的用户会显示普通立绘。

### 安装 / 升级

下载 **dsh-whale-pet-v0.5.0.zip**，完整解压到固定文件夹，运行 **install.bat**，再在 DSH 中按 **Ctrl + R** 刷新。升级时覆盖同一文件夹里的文件；如果换了位置，请重新运行安装脚本。原有设置会保留。React 与 Cordis 由 DSH 提供，无需安装 Node.js。

### 须知

- 通过账户服务读取余额，需要在 DSH 中登录 DeepSeek 账号。只使用 API Key 时 DSH 没有余额可显示；在旧版 DSH 上，打开 DSH 账户设置仍可作为后备读取方式。
- 法定节假日表目前覆盖 2026 年。补上次年官方安排之前，2027 年落在工作日的节假日可能显示为高峰，设置中会给出提示。
- 已在模拟 DSH 页面中用真实插件包检查。验证项：构建、类型检查、运行包语法及 **84 项自动测试**。如果你的 DSH 版本里表现不同，欢迎反馈。
- 插件不保存也不外发聊天记录，偏好只保存在你的电脑上。
