# v0.8.5 · 伸懒腰、剧场开关与设置整理 / Stretch, Theatre switch and tidier settings

## 中文

- **伸个懒腰（Live2D）。** 在 DSH 里或桌面上静静待着几秒后，她偶尔会把双手举过头顶伸个懒腰，然后放松肩膀；两次之间至少隔 90 秒。剧场里、探头时、安静模式和系统减少动态效果开启时不会出现。动鼠标、开始回答或把她拎起来，她会顺势把手收回，不会突然弹回。
- **悬停菜单的“剧场”变成开关。** 开着时点击 DSH 的聊天输入框进入剧场，关掉后输入框保持普通聊天，选择会被记住；**Alt+T** 随时都能进入剧场。桌面上没有输入框，菜单里的“剧场”仍然直接打开剧场。
- **设置整理。** 最上面依次是账户余额、峰谷时段，然后是“去桌面陪我”（桌面上是“回 DSH 里陪我”），上下留出空隙；原来的“进入剧场模式”卡片去掉了。
- **去桌面更顺手。** 桌面版没在运行时，“去桌面陪我”会尝试直接启动它（新版 `DaFeiYu.exe` 需要先手动打开过一次）；她离开 DSH 和出现在桌面时各有一段短动画。
- **英文时段名统一为 Peak / Off-peak**，中文仍是梁文峰 / 梁文谷。
- **修复：** 桌面版刚启动、还没连上 DSH 时，菜单和设置会误当作在 DSH 里（剧场打不开、设置显示“去桌面陪我”）。
- 使用说明和 README 截图换成了当前界面。

**插件：** 下载 **dsh-whale-pet-v0.8.5.zip**，解压到原来的插件目录覆盖，双击 **install.bat**（目录没变可以跳过），在 DSH 按 Ctrl+R。设置、互动记录和导入的模型都会保留。

**桌面版：** 下载 **dsh-whale-pet-desktop-v0.8.5-win-x64.zip**，解压到任意文件夹，双击 **DaFeiYu.exe**。要和 DSH 联动，DSH 里的插件也需要是 v0.8.5。模型不随下载包提供，需要在桌面版设置里导入一次。桌面模式还是预览。

验证：Node 自动测试、构建、两套类型检查，Windows 上的插件包与安装／卸载检查、桌面版打包与 ASAR 逐字节检查；伸懒腰的手臂路径在模型网格上核对过不会超出画面；设置、剧场和探头在 Electron 中用真实构建与模拟的 DSH 页面截图检查过。从 DSH 冷启动桌面版（`dsh-whale-pet://show`）只在模拟环境和单元测试中检查过，尚未在真实 DSH 里测试。

## English

- **A stretch (Live2D).** After a few quiet seconds in DSH or on the desktop she now and then stretches both arms over her head and lets her shoulders settle, at least 90 seconds apart. Not in the theatre, while peeking, in Quiet mode or with reduced motion. Move the pointer, start an answer or pick her up and she brings her arms down smoothly instead of snapping back.
- **Theatre in the hover menu is now a switch.** While it is on, clicking the DSH chat box opens the theatre; while it is off, the chat box stays a normal chat box. The choice is remembered, and **Alt+T** opens the theatre any time. On the desktop, where there is no chat box, Theatre in her menu still opens the theatre directly.
- **Tidier settings.** At the top come your balance, the pricing period and then “Keep me company on the desktop” (“Back into DSH” on the desktop), with room around it; the separate “Open theatre” card is gone.
- **Smoother trip to the desktop.** When the desktop app is not running, “Keep me company on the desktop” tries to start it (open the updated `DaFeiYu.exe` once by hand first); she leaves DSH and arrives on the desktop with a short animation.
- **English names the pricing periods Peak / Off-peak**; Chinese keeps 梁文峰 / 梁文谷.
- **Fix:** right after the desktop app started and before it connected to DSH, her menu and settings behaved as if she were in DSH (Theatre did not open, Settings offered “Keep me company on the desktop”).
- The user guides and README screenshots show the current interface.

**Plugin:** download **dsh-whale-pet-v0.8.5.zip**, extract it over your plugin folder, run **install.bat** (optional if the folder did not move) and press Ctrl+R in DSH. Preferences, discoveries and the imported model are kept.

**Desktop app:** download **dsh-whale-pet-desktop-v0.8.5-win-x64.zip**, extract it anywhere and double-click **DaFeiYu.exe**. To connect with DSH, the plugin inside DSH must be v0.8.5 too. The model is not included; import it once in the desktop app's settings. Desktop mode is still a preview.

Validation: automated Node tests, build, both TypeScript checks, Windows plugin package and install/uninstall checks, desktop packaging with byte-for-byte ASAR checks; the stretch's arm path was checked against the model's meshes to stay inside her frame; settings, the theatre and peeking were checked in Electron with the real build against a simulated DSH page. Starting the desktop app from DSH (`dsh-whale-pet://show`) was checked only in a simulated page and unit tests, not yet in a real DSH.
