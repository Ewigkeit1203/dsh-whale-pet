# v0.5.1 · 快速修复 / Hotfix

## 中文

- 修复点击聊天框的添加文件、权限、模型等按钮误入剧场，恢复正常文件选择流程；只有点击文字输入区才自动进入剧场。
- 修复退出剧场时角色从屏幕中央滑回的问题，桌宠直接在保存位置恢复。

下载 **dsh-whale-pet-v0.5.1.zip**，解压覆盖原插件目录，运行 install.bat，再在 DSH 中按 Ctrl+R。偏好保留。

构建、类型检查、运行包语法及 86 项测试通过；已在实际 DSH 检查文件选择、权限及模型菜单。无其他功能改动。

## English

- Attachment, permission, model and other composer controls no longer enter theatre mode. Automatic entry responds only to the text editor, keeping native file selection available.
- Exiting theatre restores the companion at its saved position without sliding from the centre of the screen.

Extract **dsh-whale-pet-v0.5.1.zip** over the existing plugin folder, run install.bat and press Ctrl+R in DSH. Preferences are retained.

Build, type checking, bundle syntax and 86 tests pass. Native file selection, permission and model menus were checked in DSH.
