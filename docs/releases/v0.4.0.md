# v0.4.0 — A clearer stage, a livelier whale / 更清爽的剧场，更生动的大肥鱼

[English](#english) | [中文](#chinese) | [Changelog / 更新日志](../../CHANGELOG.md)

## English

This release focuses on visual polish, unobtrusive companionship and reliable controls. It includes the product-review improvements since v0.3.0.

### Highlights

- Airier grouped settings with a fixed header and a separate themed scroll area. Restore-defaults, readable themes, local names and font size controls.
- Borderless size dots: five snapping positions, with a stronger blue middle mark for the default. Text size is a continuous slider with an immediate numeric readout.
- Expanded reading keeps the character's face above the panel; the stage no longer has a rectangular halo or stray feet below the dialogue.
- New **Dizzy.png**, supplied by the creator, replaces the thinking placeholder during fast-drag dizziness. All **12 illustrations** remain embedded; no extra requests or runtime dependencies.
- More visible light-theme selections, full-width prose, measured-width pagination, inline code and emphasis, one page indicator, short-text reveal with punctuation pauses, and an expanded reading toggle.
- Settings follow dragging while staying stable during resizing. Normal fade remains clickable; Alt temporarily enables click-through. Alt+W toggles the pet; Alt+T toggles theatre. Opening settings hides the toolbar.
- A reversible quiet preset, docked peek mode, reduced-motion and foreground handling, first-run tips, optional completion notifications, configurable names and local selector-only Doctor diagnostics.
- Repository cleanup: guides, release notes and handover under docs/; duplicate installers and unused source artwork removed; packaging and links updated. New contribution and artwork-rights documents.

### Install / upgrade

Download **dsh-whale-pet-v0.4.0.zip**, fully extract to a permanent directory, run **install.bat**, then refresh DSH with **Ctrl + R**. On upgrade, replace the existing directory contents or rerun the installer if the directory changed. Sound starts muted; enable Character sounds in Settings. DSH supplies React and Cordis; end users need no Node.js installation.

### Validation and limits

Build, typecheck, bundle syntax and **39 automated tests** passed. Settings, light-theme selection and standard/expanded stage layout were checked in DSH. Code/list formatting is intentionally lightweight; tables are plain text. Hit regions approximate the image alpha envelope. Recorded speech/TTS, differential mouth/blink artwork and daily usage accounting are not included. System notification delivery and broader host versions need further real-use feedback. No conversation history is persisted or sent to an extra service.

## 中文

本版以视觉打磨、减少遮挡和可靠操作为主，包含 v0.3.0 之后的产品评审改进。

### 主要更新

- 设置分组和间距更舒展，固定标题与独立主题滚动区；增加恢复默认、称呼及文字大小控制。
- 大小恢复为无框圆点：五个吸附档位，中间蓝点加粗代表默认大小。字号改为连续滑条，数字实时更新。
- 大屏阅读时在面板上方保留角色脸部；移除突兀的矩形光晕和对话框下方露脚。
- 接入作者新绘制的 **Dizzy.png**，快速摇晃后使用专属眩晕图，不再借用思考图。全部 **12 张图**继续内嵌，无额外请求或新增运行依赖。
- 加深浅色选中态，释放正文宽度；按测量行宽分页，保留行内代码与粗体、单一页码、短文逐字与标点停顿，支持大屏阅读切换。
- 菜单跟随拖拽，调整大小时保持稳定；普通淡化仍可点击，仅按住 Alt 临时穿透。Alt+W 显隐桌宠、Alt+T 切换剧场。打开设置时收起工具栏。
- 可恢复的安静预设、贴边探头、减少动态效果与前后台处理、首次引导、可选完成通知、自定义称呼和本地 Doctor 诊断。
- 整理仓库：指南、发布说明、交接移入 docs/；移除重复安装脚本和未引用旧图，同步打包与链接，补充投稿及美术权限说明。

### 安装 / 升级

下载 **dsh-whale-pet-v0.4.0.zip**，完整解压到固定目录，运行 **install.bat**，再在 DSH 中按 **Ctrl + R** 刷新。升级时覆盖原目录内容；移动目录后请重新运行安装脚本。人物音效默认关闭，可在设置中开启。React 与 Cordis 由 DSH 提供，普通用户无需安装 Node.js。

### 验证与边界

构建、类型、运行包语法及 **39 项自动测试**通过；已在 DSH 检查设置、浅色选中态和标准/大屏立绘布局。代码与列表排版为轻量实现，表格仍按文本显示。点击区域近似图片透明轮廓；录音/TTS、真实嘴型/眨眼差分及今日用量统计不在本版范围内。跨系统通知与更多宿主版本仍需实际反馈。插件不持久化聊天历史，也不向额外服务发送对话。
