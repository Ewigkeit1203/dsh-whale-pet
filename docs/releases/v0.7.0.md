# v0.7.0 · Live2D 与安装修复 / Live2D and installer recovery

## 中文

- 可选 Live2D：本机导入、鼠标注视、原生物理、日常待机、桌宠／剧场独立尺寸和触摸反馈；保留内嵌插画作为默认和降级显示。
- 拎起使用校准后的双臂外侧短弧，短暂挣扎后放松；悬空膝盖内并、小腿稍分，松手轻微屈膝缓冲。修正点击下移与快速反向再抓取跳动。
- 待机预算、动画时钟、动作采样与模型缓存生命周期修正；隐藏时停止绘制，失去 WebGL 上下文后重建。测试和静态几何检查不代表硬件帧率保证。
- 安装器改为 Windows CRLF 启动器＋独立 PowerShell 脚本，支持中文／特殊字符路径、移动后更新、修改前备份、只卸载本插件。附带旧版安装器修复小包，详见[安装修复](../INSTALLATION_RECOVERY.md)。

下载 `dsh-whale-pet-v0.7.0.zip`，完整解压到固定目录，运行 `install.bat`，在 DSH 按 Ctrl+R。修复小包仅用于已有旧版目录，不能单独安装。两种 ZIP 均提供 SHA-256。

**模型不随包提供，也不是必需项。** 作者禁止擅自重新上传模型；请从[神宫凉子原发布渠道](https://space.bilibili.com/13737731)下载，再在 设置 › 角色模型 导入。原画及拆分：神宫凉子；Live2D 建模：霓虹猫_NeonNeko。同一 DSH 存储环境正常升级会保留已导入模型，换电脑或清理应用数据后可能需重新导入。

验证包括构建、类型与运行包语法、155 项 Node 回归，以及 Windows 安装／卸载、实际 ZIP 内容／校验和／解压后安装检查。最新腿姿完成真实模型静态检查，窗口控制工具初始化失败，实际 DSH 动态观感和 GPU 帧耗时仍待验收。未接入 Agent 自动控制接口。

## English

Optional local Live2D support adds pointer tracking, native physics, idle performances, separate desktop/theatre sizes and touch reactions while retaining embedded illustration fallback. Calibrated arm arcs, relaxed suspended legs and a planted-foot landing replace the previous pickup snap and whole-image landing compression. Idle scheduling, animation timing, motion sampling and cached-stage cleanup reduce avoidable work.

Windows installation now uses CRLF launchers and a standalone PowerShell script with path-safe registration, backups, moved-folder updates and targeted uninstall. A separate installer-fix ZIP helps existing older versions without replacing their runtime. See [installation recovery](../INSTALLATION_RECOVERY.md).

Extract the complete `dsh-whale-pet-v0.7.0.zip`, run `install.bat` and refresh DSH. The repair ZIP alone is not a plugin. Both archives include SHA-256 files. Live2D is optional and the model is not redistributed: obtain it from its author and import it in Settings. A normal upgrade in the same DSH storage environment retains an imported model.

Validation covers 155 Node tests, build, type checks, bundle syntax, Windows install/uninstall and archive smoke checks. Actual-model static geometry was checked; interactive DSH validation and GPU profiling of the latest leg poses remain outstanding because window control could not initialize. Agent-driven model control is not included.
