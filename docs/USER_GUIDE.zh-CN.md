## 安装、升级与卸载

1. 从 [Releases](https://github.com/Ewigkeit1203/dsh-whale-pet/releases) 下载最新的 `dsh-whale-pet-vX.Y.Z.zip`。
2. **完整解压**到一个固定的文件夹，例如 `D:\dsh-whale-pet`。解压后的文件要一直保留，DSH 每次启动都从这里加载她。
3. 双击文件夹里的 `install.bat`，然后打开 DSH，或在已打开的 DSH 窗口按 **Ctrl + R** 刷新。

- **升级**：把新版本解压到同一个文件夹覆盖即可，设置和已导入的 Live2D 模型都会保留。换了文件夹的话，在新文件夹里再运行一次 `install.bat`。
- **卸载**：双击 `uninstall.bat`，再刷新 DSH。本机保存的设置会保留。
- `installer` 文件夹是安装脚本要用的，请不要删除。
- 不需要安装 Node.js 或其他软件。
- 旧版本（v0.1.0–v0.6.0）的安装脚本在部分 Windows 上会失败，见[安装问题与旧版本修复](INSTALLATION_RECOVERY.md)。

## 她平时在做什么

- 她住在 DSH 窗口里。你提问后，她会跟着进入**思考**（头上冒泡泡）、**回答**（出字时说话的样子）和**干饭**（回答完捧着碗吃饭）。
- 闲着的时候，她会自己散步、伸懒腰、东张西望，偶尔换个小表情。
- 中午 12 点提醒你吃午饭；凌晨 1–5 点她闲着时会犯困（眼睛半闭、画面略暗），提醒你早点睡。这两个提醒可以在 设置 › 陪伴行为 › 午饭和熬夜提醒 里关掉。
- 你在 DSH 里打字时，她不会乱跑。

## 和她互动

| 操作 | 效果 |
|---|---|
| 鼠标移到她身上 | 头顶弹出快捷菜单：剧场、设置、安静模式、探头；最近的回答里有代码时，还有“复制代码” |
| 点击她 | 打开设置 |
| 拖动她 | 把她拎起来：先扑腾，再垂下来跟着鼠标晃，松手落地。设置打开时，她和面板一起移动 |
| 在她头上来回移动鼠标 | 摸头，她会满足或害羞，还会叫你设置的称呼 |
| 摸尾巴（Live2D） | 害羞地躲开；一直摸会生气 |
| 拎着她快速晃 | 晃晕了，要缓一会儿 |
| 一直戳她 | 小彩蛋，自己试试 |

按住 **Alt** 时她变成半透明，鼠标可以点穿她，操作她身后的东西。

## 头顶小标签

- **峰谷时段**：显示现在是梁文峰（高峰）还是梁文谷（空闲，半价）时间，以及到几点结束。点击这个标签，她会再播报一次。按 DeepSeek 官方规则：北京时间工作日 9:00–12:00、14:00–18:00 为高峰，其余时间、周末和法定节假日为空闲。
- **余额**：在 DSH 里登录 DeepSeek 账号后自动显示，点击查看更新时间或重试。读不到时显示“余额 —”；只用 API Key 时 DSH 没有余额可显示。
- **选择显示哪些**：设置 › 陪伴行为 › 头顶显示，可选“都显示 / 峰谷 / 余额 / 都不显示”。
- 余额低于设定金额时她会提醒你（设置 › 陪伴行为，填 0 为不提醒）。

## 探头

不想她挡住对话时，让她躲到窗口右边只探出半个身子：

- 点悬停菜单里的 **探头**，或按 **Alt+P**（可以在 设置 › 外观 里换成别的快捷键）。再按一次，她回到原来的位置。
- 探头时她不散步、不闲聊。被晃晕时没法探头。
- 探头时头顶只留一个小菜单：**设置｜回来 Alt+P**，下面是峰谷时间和余额。回来后恢复完整菜单。**【下个版本】**
- 探头时点“设置”，她会留在原地，设置面板在她左边打开。**【下个版本】**
- 使用 Live2D 模型时，她斜着身子探出来、一只手伸向窗口边缘；没有模型时用专门的探头插图。

## 对话剧场

GalGame 风格的全屏对话：

- **进入**：点击 DSH 的聊天输入框（可在 设置 › 剧场阅读 里关闭这个自动进入），或按 **Alt+T**，或点悬停菜单里的“剧场”。
- **翻页**：第一次点击文字会把当前段显示完，再点一次翻到下一页。也可以用 ←/→ 或 Enter。
- **底部按钮**：回顾（看页面上已加载的问答）、自动（自动翻页）、快进（或按住 Ctrl，跳到最后一段）、隐藏、大屏，以及“⋯”菜单（音效、阅读方式、主题、语言）。
- **左上角小按钮**：
  - 音乐：三首内置曲目（日常轻快 / 宁静闲聊 / 深夜治愈），也可以用自己的音乐文件。
  - 背景：跟随时间自动切换，或选四套场景之一、透明（继续看到 DSH）、你自己的图片、每次随机。
  - 剧场设置：文字速度、字号、打字机效果、自动翻页、音效。
- 剧场里也能摸头、摸尾巴和戳她（点她算戳，不会翻页）。
- **退出**：按 **Esc**，或点“退出”。选了“透明”背景时，点击背景也会退出。

## Live2D 模型（可选）

不导入模型时，她用原版插图。导入免费的 **DeepSeek-chan（大肥鱼）Live2D 模型** 后，她会动起来：眼睛和头跟着鼠标，头发裙摆有物理摆动，还有更多动作和表情。

1. 从作者的[获取页面](https://gf.bilibili.com/item/detail/1109618072?noTitleBar=1&from=mall-up_itemDetail&msource=cps_comments_13737731_cont-1-117527753588880&track_id=__BGMT__)领取模型（原画及拆分：神宫凉子；Live2D 建模：霓虹猫_NeonNeko）。
2. 把压缩包**完整解压**。
3. 打开 设置 › 角色模型 › **导入模型文件夹**，选择含有 `大肥鱼.model3.json` 的那个文件夹（也可以把文件夹直接拖到导入卡片上）。

- 模型只保存在本机，插件不附带、也不会上传模型文件。正常升级插件会保留已导入的模型；清理应用数据或换电脑后需要重新导入。
- 设置 › 角色模型 里可以单独调整桌宠和剧场里的模型大小、随时关闭 Live2D 回到插图，或移除模型。
- 公开分享用这个模型制作的内容时，请按作者要求注明模型来源和制作人员。

## 设置一览

点击她即可打开设置。设置面板贴在她身旁，不会挡住她。

| 分组 | 内容 |
|---|---|
| 外观 | 浅色/深色主题、界面语言（中文/English）、大小、透明度、文字大小、探头快捷键、探头开关 |
| 角色模型 | 导入、重新导入或移除 Live2D 模型；桌宠和剧场的模型大小；是否使用 Live2D |
| 声音 | 人物音效（默认静音）、音量 |
| 陪伴行为 | 安静模式（暂停闲聊、音效和散步）、省电模式、裙摆飘动、闲置时散步、午饭和熬夜提醒、峰谷时段播报、怎么称呼你、她的昵称、头顶显示、低余额提醒、每碗饭额度 |
| 剧场阅读 | 逐字显示、文字速度、自动下一段、点击输入框进入剧场 |
| 互动图鉴 | 你已经发现的互动；再看一次新手引导 |
| 高级 | 回答完成提醒、后台完成通知（会请求系统授权）、兼容性检查 Doctor、恢复默认设置 |

**省电模式**：Live2D 最高 30 帧，待机 20 帧，切到别的软件时 10 帧。电脑风扇响或觉得卡时可以打开。

## 快捷键

| 快捷键 | 作用 |
|---|---|
| Alt+P | 探头 / 回来（可在设置里改） |
| Alt+T | 打开/关闭剧场 |
| Alt+W | 隐藏/显示她 |
| 按住 Alt | 点穿她 |
| Tab 选中她后按 Enter | 打开设置 |

剧场里：←/→ 或 Enter 翻页，按住 **Ctrl** 快进，**L** 回顾，**A** 自动，**H** 隐藏界面，**M** 音效，**Esc** 先关闭菜单、再退出剧场。

## 桌面模式（预览）

> 这是预览功能，还在完善中。

让大肥鱼离开 DSH 窗口，直接待在系统桌面上：透明、始终置顶、不占任务栏，鼠标不在她身上时可以正常点击桌面上的其他东西。

- **下载即用** **【下个版本】**：从 [Releases](https://github.com/Ewigkeit1203/dsh-whale-pet/releases) 下载 `dsh-whale-pet-desktop-vX.Y.Z-win-x64.zip`，解压到任意文件夹，双击 `DaFeiYu.exe`。不需要安装 Node.js。Windows 提示“未知发布者”时，点“更多信息” › “仍要运行”。删除这个文件夹就是卸载。
- **从源码运行（开发者）**：在插件文件夹里双击 `desktop\大肥鱼桌面.vbs`（不开终端窗口），或运行 `npm.cmd run desktop`（启动后可以关掉终端）。
- **退出 / 隐藏**：右键托盘里的蓝色小圆图标，选“退出桌面模式”；**Alt+Shift+H** 隐藏或显示。
- **和 DSH 联动**：DSH 和桌面模式都开着时会自动连接。你在 DSH 里提问，桌面上的她也会跟着思考、回答、干饭，余额也会显示出来。托盘菜单第一行和她设置里“头顶显示”下面都会显示连接状态。
- 桌面上的她有自己的设置和模型，需要在她的设置里再导入一次 Live2D 模型。

## 常见问题

**DSH 里看不到她？**
确认解压的文件夹还在、运行过 `install.bat`，然后在 DSH 里按 Ctrl + R。还不行的话，见[安装问题与旧版本修复](INSTALLATION_RECOVERY.md)。

**余额显示“—”？**
需要在 DSH 里登录 DeepSeek 账号；只用 API Key 时没有余额。点击余额标签可以看具体原因或重试。

**半夜她看起来没精神、颜色发暗？**
这是熬夜提醒：凌晨 1–5 点她闲着时会犯困。可以在 设置 › 陪伴行为 里关掉“午饭和熬夜提醒”。如果白天也这样，检查一下电脑时间是否正确（装了 Windows 和 Linux 双系统时，时间常常会差 8 小时）。

**觉得卡？**
打开 设置 › 陪伴行为 › 省电模式。

**她挡住东西了？**
按 Alt+P 让她探头，或按住 Alt 点穿她，或按 Alt+W 先藏起来。

## 隐私

- 设置只保存在本机。你添加的剧场图片、音乐和 Live2D 模型只保存在本机浏览器存储里，不会上传。
- 聊天记录不会被保存，也不会发送给任何额外的服务。“回顾”只读取页面上已加载的消息。
- 余额通过 DSH 自带的账户服务读取，插件不接触任何账户凭据。
- 桌面模式和 DSH 之间的连接只在你自己的电脑内部进行，不经过网络。
- 完成通知默认关闭，只有你开启时才会请求系统权限。
